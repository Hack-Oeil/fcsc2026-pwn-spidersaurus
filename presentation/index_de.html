Challenge #655

Spidersaurus

Nach einigen Rückschlägen mit der Sprache FORTH sowie der Sprache BASIC hat unser Entwickler beschlossen, mit der Version 1.3 des SpiderMonkey-JavaScript-Interpreters zu den Ursprüngen des Multimedia-Internets zurückzukehren.

Er versichert uns, dass dank der Kompilierungsparameter keine Sicherheitslücke ausnutzbar ist; zudem garantiert er uns, dass der Code für das Jahr 2000 zertifiziert (Y2K-fähig) ist.

Ein anonymer Hacker hat uns jedoch eine mysteriöse Datei test.js übermittelt, die offenbar ein Lesen von nicht initialisiertem Speicher auslöst. Können Sie beweisen, dass unser Entwickler unrecht hat, indem Sie den Inhalt der Variable flag auslesen?

Hinweis: Das Programm wurde mit clang-17 (unter Debian 13 i386) kompiliert, läuft jedoch unter Debian 13 amd64 (mit installiertem libc6:i386).
