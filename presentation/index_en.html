Challenge #655

Spidersaurus

Following some mishaps with the FORTH language, as well as the BASIC language, our developer decided to return to the origins of the Multimedia Internet using version 1.3 of the SpiderMonkey JavaScript interpreter.

He assures us that no security vulnerability is exploitable, thanks to the compilation flags; moreover, he guarantees that the code is Y2K compliant.

However, an anonymous hacker sent us a mysterious test.js file that seems to trigger an uninitialized memory read. Can you prove our developer wrong by reading the contents of the flag variable?

Note: The program is compiled with clang-17 (under Debian 13 i386), but runs under Debian 13 amd64 (with libc6:i386 installed).

File(s) to study:

  • JSRef.zip
  • spidersaurus
  • spidersaurus.patch
