Challenge #655

Spidersaurus

Após alguns contratempos com a linguagem FORTH, bem como com a linguagem BASIC, o nosso desenvolvedor decidiu regressar às origens da Internet Multimédia através da versão 1.3 do interpretador JavaScript SpiderMonkey.

Ele garante-nos que nenhuma vulnerabilidade de segurança é explorável, graças às opções de compilação; além disso, garante que o código está certificado para a transição para o ano 2000.

No entanto, um hacker anónimo enviou-nos um misterioso ficheiro test.js que parece despoletar uma leitura de memória não inicializada. Consegue provar que o nosso desenvolvedor está errado lendo o conteúdo da variável flag?

Nota: O programa é compilado com clang-17 (em Debian 13 i386), mas é executado em Debian 13 amd64 (com libc6:i386 instalado).

Arquivo(s) para estudar:

  • spidersaurus
  • spidersaurus.patch
